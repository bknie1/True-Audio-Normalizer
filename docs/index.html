TAN

True Audio Normalizer - fixing poorly mixed sound in real time. Open source, no metadata cheats, no walled garden.

I kept riding the volume remote through every movie: up for the whispers, down for the explosions. The industry already solved this once - Dolby Volume and friends do it by baking loudness metadata into the mix at mastering time, then lock the fix inside licensed hardware. I hate walled gardens, so TAN does the job blind instead: it measures perceived loudness the way your ear does and rides gain in real time, and it's MIT licensed Rust you can actually read.

How it works

Three stages, all classical DSP, all in tan-core:

  1. Perceptual loudness metering - ITU-R BS.1770 K-weighting (shelf + high-pass biquads), so gain decisions track how loud things sound, not raw sample amplitude.
  2. Baseline-anchored gain riding - the engine tracks the content's own average loudness (following louder material quickly, sinking toward quiet slowly, the way perception anchors on the prominent level) and levels around that, never toward an absolute target - so enabling TAN never changes how loud things feel overall. Quiet dialogue is boosted toward the baseline and loud peaks pulled down to it, with separate speed limits per direction and a gate so silence is never amplified into hiss. Cut speed scales with overshoot, so a big correction finishes within ~50 ms of a loud onset - masked by the onset itself - while small corrections stay too slow to hear as pumping.
  3. Look-ahead limiting - output is delayed 8 ms while the limiter watches incoming audio, so gain ramps down before a peak arrives instead of clicking after it.

Reproduce it

git clone https://github.com/bknie1/True-Audio-Normalizer
cd True-Audio-Normalizer
cargo run --release -p tan-cli -- gen demo-input.wav
cargo run --release -p tan-cli -- process demo-input.wav demo-output.wav movie

Roadmap

  • Now - hand-written WAV codec, perceptual metering, baseline-anchored AGC, look-ahead limiter, movie/music profiles, a native shared library, a first-cut Windows live tool, tagged releases with installers, CI on Windows/macOS/Linux.
  • Next - a real Windows Audio Processing Object, so TAN sits in the system audio pipeline directly instead of needing a second device or a virtual cable.
  • Then - blind dialogue detection: a lightweight real-time neural model (DeepFilterNet-style) so speech specifically stays intelligible in the mix - the thing Dolby needs mastering-time metadata to do.
  • After that - live system-audio adapters for macOS/Linux, mobile.
