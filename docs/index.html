TAN

True Audio Normalizer - fixing poorly mixed sound in real time. Open source, no metadata cheats, no walled garden.

Movie dialogue you can't hear, action scenes that blow you out of the chair. The industry fix (Dolby Volume and friends) leans on loudness metadata embedded at mastering time and ships locked inside licensed hardware. TAN does the job blind - measuring perceived loudness the way a human ear does and riding gain in real time - and it's MIT licensed Rust you can read.

How it works

Three stages, all classical DSP, all in tan-core:

  1. Perceptual loudness metering - ITU-R BS.1770 K-weighting (shelf + high-pass biquads), so gain decisions track how loud things sound, not raw sample amplitude.
  2. Two-way gain riding - quiet dialogue is boosted toward a target, loud passages are pulled down, with separate speed limits per direction, fast recovery after cuts, and a gate so silence is never amplified into hiss. Cut speed scales with overshoot, so a big correction finishes within ~50 ms of a loud onset - masked by the onset itself - while small corrections stay too slow to hear as pumping.
  3. Look-ahead limiting - output is delayed 8 ms while the limiter watches incoming audio, so gain ramps down before a peak arrives instead of clicking after it.

Reproduce it

git clone https://github.com/bknie1/TAN
cd TAN
cargo run --release -p tan-cli -- gen demo-input.wav
cargo run --release -p tan-cli -- process demo-input.wav demo-output.wav movie

Roadmap

  • Done - hand-written WAV codec, perceptual metering, two-way AGC, look-ahead limiter, movie/music profiles, CI on Windows/macOS/Linux.
  • Next - blind dialogue detection: a lightweight real-time neural model (DeepFilterNet-style) so speech specifically stays intelligible in the mix - the thing Dolby needs mastering-time metadata to do.
  • Then - live system-audio adapters per platform (Windows APO, PipeWire, Core Audio), mobile.
